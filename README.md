# Jeeviraj V — Portfolio Redesign

Redesigned cybersecurity portfolio inspired by the minimalist GitHub Octocat template.

## Features
- **Window Frame:** macOS-style top bar with traffic light buttons.
- **Hero Section:**
  - `HELLO!` red badge header.
  - `A little about me` display typography.
  - Rounded skill pills (`Cybersecurity`, `Ethical Hacking`, `SOC Analyst`, `Python`, `React`, etc.).
  - Metadata and stats bar (Location, GitHub, 1st Prize CTF, 8.01 CGPA).
  - **Signature Hanging Red Badge:** Realistic cord, metallic eyelet, tilted badge with mouse-reactive sway physics. Toggle between the Octocat security mascot and your portrait photo.
- **Core Capabilities & Technical Arsenal:** SOC, Ethical Hacking, AI/LLM Security (CLLMSE), Full-Stack.
- **Featured Projects:** HostelFix (IoT/YOLO/OpenCV/PostgreSQL), AI-NIDS (FastAPI/React/Scikit-learn), CyberGuard AI (IJRES Published Paper), Python SOC Suite.
- **Achievements & Trophies:** 1st Prize Mirage CTF 2.0, 2nd Prize SUSTAINVERSE 2K26, Top 10 $N1PH3RS 3.0, Rank #70 z0d1ak CTF.
- **Education Journey:** Sri Shakthi Institute of Engineering & Technology, Spark Matric HSS, Govt HSS.
- **All 17 Verified Credentials:** Filterable by CTF, Internship, Course with instant Lightbox preview.
- **Direct Contact:** 1-click copy for Email & Phone, direct LinkedIn & GitHub links.

## How to Preview
Double-click `index.html` to open in any browser (Chrome, Edge, Firefox).

## How to Deploy to GitHub Pages (jeevicyber28.github.io)
1. Copy all files from this folder (`portfolio-redesign`) into your `jeevicyber28.github.io` repository.
2. Commit and push:
   ```bash
   git add .
   git commit -m "Redesign portfolio matching clean minimalist template"
   git push origin main
   ```
3. Your site will automatically update at https://jeevicyber28.github.io/
